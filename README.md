# De cero a online: Tu portafolio de ciencia de datos en 90 minutos

**Workshop gratuito — FES Acatlán UNAM · Diplomado Ciencia de Datos**

Repositorio con todos los materiales del workshop donde los participantes crean su página personal y portafolio publicado en GitHub Pages, desde cero, en una sesión.

---

## ¿De qué trata el workshop?

En 90 minutos, los asistentes pasan de no tener presencia en internet a tener una página personal publicada con su nombre y sus proyectos. No se instala nada — todo se hace desde el navegador.

## Cómo usar la plantilla

1. Abre la plantilla en línea: [benjov.github.io/github-pages-workshop/template/](https://benjov.github.io/github-pages-workshop/template/)
2. Ábrelo en cualquier editor de texto (o directamente en GitHub)
3. Busca los comentarios `<!-- CAMBIA ESTO: ... -->` y sustituye con tu información
4. Súbelo a tu repositorio `[tu-usuario].github.io` en GitHub
5. Tu página ya está publicada en `https://[tu-usuario].github.io`

No necesitas instalar nada ni saber programar.
