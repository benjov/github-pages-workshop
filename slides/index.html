Bloque 1 · 10 min

¿Por qué importa tener un portafolio?

En ciencias sociales y humanidades:


  • La mayoría tiene Word, Excel, PowerPoint.
  • Muy pocos tienen código publicado y visible.
  • Un portafolio demuestra lo que sabes hacer,
    no solo lo que estudias.
  • Es la diferencia en un proceso de selección.

¿Por qué GitHub Pages?

  • Gratuito para siempre — sin planes de pago
  • URL profesional: tu-nombre.github.io
  • Sin anuncios, sin límites de tráfico
  • Respetado en la academia y la industria
  • Funciona con un solo archivo index.html
HAZLO AHORA
Bloque 2 · 10 min

Crea tu cuenta de GitHub

  • Ve a github.com/signup en tu navegador
  • Escribe tu correo y crea una contraseña
  • Elige tu nombre de usuario — aparecerá en tu URL
  • Verifica tu correo cuando llegue el mensaje
Tip: usa tu nombre real, ej. maria-garcia
Evita números y caracteres especiales.
Bloque 3 · 15 min

El nombre mágico

GitHub publica tu página automáticamente cuando
el repositorio se llama exactamente así:

tu-usuario.github.io
  • Si tu usuario es mgarcia → crea el repo mgarcia.github.io
  • GitHub publica en → https://mgarcia.github.io
  • No necesitas configurar nada más
HAZLO AHORA

Crea tu repositorio

  • Dentro de GitHub, haz clic en el botón New (o el +)
  • En Repository name, escribe: tu-usuario.github.io
  • Selecciona Public
  • Clic en Create repository
⚠️ El nombre debe coincidir exactamente con tu usuario
incluyendo mayúsculas y minúsculas.

El momento de verdad
