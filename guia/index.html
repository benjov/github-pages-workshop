De cero a online:
tu portafolio en GitHub Pages

Sigue esta guía a tu propio ritmo. Al terminar tendrás una página personal publicada en internet con tu nombre y tus proyectos — sin instalar nada.

🌐 Cualquier navegador moderno
✉️ Una cuenta de correo electrónico
⏱️ 30–45 minutos
1

Crear tu cuenta de GitHub

GitHub es la plataforma donde viven tu código y tu página. Crear una cuenta es gratuito y solo toma unos minutos. Si ya tienes cuenta, pasa al Paso 2.

  1. a Ve a github.com/signup en tu navegador.
  2. b Escribe tu correo electrónico y crea una contraseña.
  3. c Elige tu nombre de usuario. Este nombre formará parte de la URL de tu página (https://tu-usuario.github.io), así que elige algo profesional — idealmente tu nombre o alguna variación.
  4. d Verifica tu correo cuando GitHub te envíe el mensaje de confirmación.
💡

El nombre de usuario no se puede cambiar fácilmente después. Usa algo que no te dé vergüenza poner en tu CV: tu nombre, iniciales, o algo profesional.

2

Crear el repositorio especial

En GitHub, tus archivos viven en repositorios. Hay un repositorio con nombre especial que GitHub convierte automáticamente en tu página personal.

  1. a Una vez dentro de GitHub, haz clic en el botón "New" (o el ícono "+") en la esquina superior derecha.
  2. b En el campo "Repository name", escribe exactamente:
    tu-usuario.github.io
    (sustituye tu-usuario con tu nombre de usuario real).
  3. c Asegúrate de que el repositorio sea público (la opción "Public" debe estar seleccionada).
  4. d Haz clic en "Create repository".
⚠️

El nombre del repositorio debe coincidir exactamente con tu nombre de usuario, incluyendo las mayúsculas. Si tu usuario es MariaGarcia, el repo debe llamarse MariaGarcia.github.io.

3

Crear el archivo de tu página

Una página web es un archivo de texto con extensión .html. Vamos a crear el archivo index.html directamente desde el navegador y a pegarle la plantilla del workshop.

  1. a Dentro de tu repositorio vacío, haz clic en "creating a new file" (o en el botón "Add file > Create new file").
  2. b En el campo del nombre de archivo (donde dice "Name your file..."), escribe exactamente: index.html
  3. c Descarga la plantilla del workshop desde el repositorio y copia todo su contenido.
  4. d Pega el contenido en el área de edición grande que aparece abajo del nombre.
⚠️

El archivo debe llamarse exactamente index.html (en minúsculas, sin espacios). Si se llama diferente, la página no se publicará.

Después de pegar la plantilla, baja hasta el final de la página. Encontrarás la sección "Commit changes". Ahí haz clic en el botón verde "Commit changes" para guardar el archivo.

4

Personalizar tu página

La plantilla tiene marcadores CAMBIA ESTO: en todos los lugares que debes editar. Abre el archivo index.html en GitHub, haz clic en el ícono de lápiz (✏️) para editarlo, y busca estos comentarios.

Los cambios mínimos para tener una página funcional son:

  1. 1 Título de la pestaña — Cambia "Tu Nombre — Portafolio" por tu nombre real.
  2. 2 Tu inicial en el avatar — Cambia la data-inicial="T" por la primera letra de tu nombre en mayúscula.
  3. 3 Nombre en la nav y en el hero — Reemplaza "Tu Nombre" y "Tu Nombre Apellido".
  4. 4 Título profesional — Por ejemplo: "Socióloga y analista de datos" o "Estudiante de Humanidades".
  5. 5 Links de GitHub, LinkedIn y correo — Reemplaza las URLs de ejemplo con las tuyas.

Por ejemplo, así se ve el cambio de la inicial del avatar:

HTML — Antes 
<!-- CAMBIA ESTO: Pon la primera letra de tu nombre en data-inicial -->
<div class="avatar" data-inicial="T">
HTML — Después (ejemplo: María) 
<!-- CAMBIA ESTO: Pon la primera letra de tu nombre en data-inicial -->
<div class="avatar" data-inicial="M">

Y así se ve el cambio del nombre en el hero:

HTML — Antes 
<!-- CAMBIA ESTO: Tu nombre completo -->
<h1 class="hero-nombre">Tu Nombre Apellido</h1>

<!-- CAMBIA ESTO: Tu título o rol profesional -->
<p class="hero-titulo">Estudiante de Ciencia de Datos</p>
HTML — Después (ejemplo: María) 
<!-- CAMBIA ESTO: Tu nombre completo -->
<h1 class="hero-nombre">María García López</h1>

<!-- CAMBIA ESTO: Tu título o rol profesional -->
<p class="hero-titulo">Socióloga · Analista de datos</p>
💡

Después de cada edición, baja hasta el final y haz clic en "Commit changes" para guardar. Los cambios tardan 1-2 minutos en verse en tu página.

5

Ver tu página publicada

GitHub Pages publica tu página automáticamente. Después de hacer tu primer commit, espera entre 1 y 3 minutos y luego abre una nueva pestaña.

  1. a Abre una nueva pestaña en tu navegador.
  2. b Escribe tu URL: https://tu-usuario.github.io (con tu usuario real).
  3. c ¡Tu página ya está publicada en internet! 🎉
🎉

¡Felicidades! Tienes una página personal publicada en internet que puedes compartir en tu CV, LinkedIn y redes sociales. La URL es permanente y gratuita.

Problemas comunes y soluciones

1. Espera un poco más. GitHub Pages puede tardar hasta 5 minutos la primera vez. Recarga la página con Ctrl+Shift+R (o Cmd+Shift+R en Mac).

2. Verifica el nombre del repositorio. Debe ser exactamente tu-usuario.github.io donde tu-usuario es tu nombre de usuario de GitHub, con las mismas mayúsculas.

3. Verifica que sea público. Ve a Settings de tu repositorio y asegúrate de que diga "Public".

El archivo debe llamarse exactamente index.html — en minúsculas, sin espacios, sin mayúsculas. Verifica que el nombre del archivo en tu repositorio sea correcto. Si se llama Index.html o index.HTML, renómbralo.

Opción A: Si usas una URL de internet, verifica que la dirección sea correcta y que la imagen sea accesible públicamente (abre la URL en una pestaña nueva para comprobarlo).

Opción B: Sube tu foto directamente al repositorio (botón "Add file > Upload files") y en el src de la imagen pon solo el nombre del archivo, por ejemplo: src="foto.jpg".

Si no tienes foto, la plantilla muestra tu inicial automáticamente — no pasa nada.

Los colores están definidos como variables al principio del bloque <style>, dentro de :root { ... }. Cambia los valores hexadecimales por el color que prefieras. Por ejemplo, para cambiar el color de acento (botones y detalles):

CSS
/* Cambia #0ea5e9 por el color que prefieras */
--acento: #0ea5e9;   /* azul cielo (el que viene por defecto) */
--acento: #8b5cf6;   /* morado */
--acento: #f43f5e;   /* rosa */
--acento: #10b981;   /* verde esmeralda */

Después de cada edición en GitHub, espera 1-2 minutos y luego recarga tu página con Ctrl+Shift+R (Windows/Linux) o Cmd+Shift+R (Mac). Esto fuerza al navegador a descargar la versión más reciente en lugar de mostrar la versión guardada en caché.

La plantilla tiene href="#" como placeholder en los links de proyectos. Reemplaza el # con la URL real de tu proyecto (el link a tu repositorio de GitHub o al demo). Si todavía no tienes la URL, puedes borrar el enlace completo por ahora y agregarlo después.
