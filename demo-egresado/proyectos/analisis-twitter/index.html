Análisis de sentimiento en Twitter
durante el proceso electoral 2024 en México

¿Cómo varió el sentimiento en Twitter hacia los principales partidos políticos durante la campaña presidencial de 2024? Analicé 52,847 tweets con Python y NLP para responder esa pregunta semana a semana.

📅 Junio 2024 👤 Daniela Flores Méndez 🐦 52,847 tweets ⏱ ~15 min de lectura
SECCIÓN 01

Introducción

Twitter (hoy X) se ha convertido en uno de los espacios principales de debate político en México. Durante los procesos electorales, millones de usuarios expresan opiniones, comparten noticias y debaten propuestas en tiempo real. Este flujo de texto constituye una fuente valiosa para investigar el clima político y la percepción pública de los partidos.

En este análisis me propuse responder tres preguntas:

1. ¿Qué partido genera más sentimiento positivo en Twitter durante la campaña 2024?
2. ¿Cómo evoluciona el sentimiento semana a semana conforme avanza la campaña?
3. ¿Cuáles son los temas y palabras más frecuentes en el discurso político de cada partido?

Nota metodológica: Este análisis usa TextBlob para análisis de sentimiento. TextBlob fue diseñado para inglés, por lo que los tweets fueron traducidos al inglés antes del análisis. Una mejora futura sería usar modelos entrenados en español, como BERT en español o BETO.

Recolecté tweets usando la API académica de Twitter con palabras clave asociadas a cada partido. El período de recolección abarca del 1 de febrero al 2 de junio de 2024 (día de la elección).

SECCIÓN 03

Metodología

El análisis se realizó en tres pasos: limpieza del texto, traducción al inglés, y clasificación del sentimiento con TextBlob.

In [3]:
def limpiar_texto(texto):
    # Eliminar URLs
    texto = re.sub(r'http\S+', '', texto)
    # Eliminar menciones (@usuario) y hashtags
    texto = re.sub(r'[@#]\S+', '', texto)
    # Eliminar caracteres especiales y emojis
    texto = re.sub(r'[^\w\sáéíóúüñÁÉÍÓÚÜÑ]', '', texto)
    return texto.strip().lower()

df['texto_limpio'] = df['texto'].apply(limpiar_texto)
print(f"Tweets procesados: {len(df):,}")

def obtener_sentimiento(texto):
    """Retorna polaridad: -1.0 (muy negativo) a +1.0 (muy positivo)"""
    return TextBlob(texto).sentiment.polarity

def clasificar(score):
    if score > 0.05:  return 'positivo'
    if score < -0.05: return 'negativo'
    return 'neutral'

df['score']     = df['texto_limpio'].apply(obtener_sentimiento)
df['categoria'] = df['score'].apply(clasificar)

print(df['categoria'].value_counts(normalize=True).round(3) * 100)

SECCIÓN 05

Conclusiones

El análisis muestra patrones claros en la forma en que los usuarios de Twitter se expresaron sobre los partidos durante la campaña 2024:

1. Morena y MC lideran en sentimiento positivo. Ambos partidos recibieron más del 40% de tweets con polaridad positiva, sugiriendo que sus mensajes de campaña resonaron favorablemente en la conversación digital.

2. El PRI concentra el mayor rechazo. Con un 58% de sentimiento negativo, el PRI fue el partido con peor recepción en la plataforma, consistente con su bajo desempeño electoral.

3. El sentimiento polariza en las semanas finales. La última etapa de la campaña vio una caída generalizada del sentimiento positivo, posiblemente relacionada con mayor cobertura de controversias y ataques entre candidatos.

Limitaciones y trabajo futuro: El análisis usa TextBlob, una herramienta diseñada para inglés. Una mejora significativa sería usar modelos de sentimiento nativos en español. Además, el muestreo no es aleatorio y puede sobre-representar a usuarios con mayor actividad en la plataforma.
